# کرامت‌یار — نسخه بومی اندروید با Jetpack Compose

این پروژه پس از بررسی APK نمونه ارسالی کاربر، از پوسته WebView به یک پروژه بومی Kotlin + Jetpack Compose تغییر یافته است.

## ساختار
- Android Native / Kotlin
- Jetpack Compose + Material 3
- RTL فارسی و فونت Shabnam
- بدون مجوز اینترنت؛ محتوای محلی و آفلاین
- ذخیره پیشرفت روی دستگاه با SharedPreferences
- صفحه خانه، نکات آموزشی، جزئیات فلش‌کارت، فهرست هفت سناریو، آزمون، نتیجه و مرور پاسخ‌ها، پیشرفت و منابع

## محتوا
- ۲۱ نکته آموزشی مبتنی بر منشور کرامت مادری ایران
- پنج سرفصل رسمی ۱۰ ساعته و دوره توجیهی جداگانه ۲ ساعته
- هفت سناریوی آموزشی، هر کدام سه پرسش
- بازخورد پاسخ و منبع، حدنصاب ۶۰٪ برای باز شدن مرحله بعد

## ساخت APK
GitHub Actions در `.github/workflows/android-apk.yml` با push به main یا اجرای دستی، فایل debug APK می‌سازد. خروجی در بخش Actions > Artifacts قرار می‌گیرد.

## ملاحظات
- این نسخه یک MVP بومی برای پایلوت است؛ هنوز APK کامپایل و روی دستگاه‌های مختلف آزموده نشده است.
- پیشرفت محلی است و حساب دانشجویی/همگام‌سازی ابری ندارد.
- یادآوری سیستم‌عامل هنوز پیاده‌سازی نشده است.
- محتوا پیش از استفاده رسمی باید توسط اعضای هیئت علمی مامایی و متخصص اخلاق حرفه‌ای بازبینی شود.
- از این اپ برای ثبت اطلاعات واقعی بیمار استفاده نشود.
